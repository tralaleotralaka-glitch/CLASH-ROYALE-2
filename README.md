# Clash Royale — Арена

Неофициальная браузерная фан-игра по мотивам Clash Royale. Бои проводятся локально против бота и не требуют регистрации или игрового сервера. Онлайн-PvP и связь с аккаунтом Supercell не предусмотрены.

## Запуск

```sh
npm ci
npm run dev
```

- `npm run build` — собрать статические файлы в `dist/`.
- `npm test` — проверить движок боя.

## Управление

Выберите карту нажатием или клавишами **1–4**, затем укажите точку на поле. Войска можно выставлять на своей половине, а заклинания — на обеих. Для игры с клавиатуры переведите фокус на арену, перемещайте прицел стрелками и нажмите **Enter**. **Esc** снимает выбор.

В колоде восемь карт. Четыре находятся в руке, а использованная карта уходит в конец очереди. Последняя минута ускоряет восстановление эликсира. Если по истечении трёх минут счёт равный, бой переходит в дополнительное время. Колода, настройки и результаты сохраняются в этом браузере.

## Материалы

Арты карт и бойцов — игровые материалы Supercell из [архива RoyaleAPI](https://github.com/RoyaleAPI/cr-api-assets). Проект не одобрен и не спонсируется Supercell. См. [политику фан-контента](https://supercell.com/en/fan-content-policy/). Значки интерфейса — Lucide; лицензия в `THIRD_PARTY_NOTICES.md`.

## APK для Android

Для установки нужен Android 8.0 (API 26) или новее с актуальным Android System WebView. Интернет для игры не нужен. Сборка подписана отладочным ключом и предназначена для прямой установки, а не для Google Play.

Готовый APK можно скачать из [GitHub Releases](https://github.com/tralaleotralaka-glitch/CLASH-ROYALE-2/releases). Workflow **Android APK** также сохраняет APK в артефактах. Для публикации новой версии обновите `versionCode` и `versionName` в `android/app/build.gradle`, затем запустите workflow с опцией публикации или отправьте коммит с пометкой `[publish android]`.

Сборка вручную: с установленными JDK 17, Gradle 8.9, Android SDK Platform 35 и Build Tools 35.0.0 выполните:

```sh
npm ci
npm run build
gradle --project-dir android :app:assembleDebug
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.
